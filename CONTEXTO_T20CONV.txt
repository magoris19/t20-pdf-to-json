1. OBJETIVO
--------------------------------------------------------------------------------
Automatizar a criação de ameaças (NPCs) de Tormenta20 no Foundry VTT:
PDF do livro (ex.: Ameaças de Arton) -> texto da ficha -> JSON de ator do
sistema "tormenta20" do Foundry, com o máximo de automação: rolagens de
ataque/dano/cura, bônus condicionais (ex.: Avesso à Honra do Oni), efeitos
ativos, magias com valores finais etc.

Ambiente do usuário:
- Foundry VTT v12 (core 12.331), sistema tormenta20 v1.4.213.
- Módulo próprio do usuário: https://github.com/magoris19/ameacas-de-arton-cdm
  (compêndio "ameacas-de-arton-cdm", packs: ameacas [Actor], items [Item],
  journals). Feito à mão; serve de base de convenções, mas a ideia é
  MELHORAR os processos, não copiar erros.
- Módulo de ícones requerido: cdm-icons (tokens em modules/cdm-icons/tokens-t20/).
- PC: Ryzen 5 3500, RTX 5060 8GB (relevante só se for usar OCR/VLM local).

2. DECISÕES DE ARQUITETURA
--------------------------------------------------------------------------------
- Programa em Python local em vez de "chat especializado": custo zero de
  tokens por ficha, resultado determinístico e repetível.
- PDFs oficiais de T20 têm texto digital -> NÃO precisa de OCR; usar PyMuPDF
  (lê fontes: negrito/itálico ajudam a achar rótulos). OCR (PaddleOCR) só se
  algum PDF for escaneado.
- Parte fixa da ficha (cabeçalho, defesas, ataques, atributos, perícias):
  regex. Habilidades em texto livre: motor de regras (regex de padrões T20).
- LLM (API Claude, modelo barato) fica para DEPOIS, só para as habilidades
  que as regras não cobrirem — medir primeiro quantas sobram com o PDF real.
- Biblioteca: o compêndio do usuário (1.761 poderes, 312 magias, 883 armas)
  vira um índice reutilizável: ícones, escola/círculo de magias, e reuso de
  poderes já configurados quando o texto é idêntico.

3. FLUXO
--------------------------------------------------------------------------------
  PDF --tools/extrair_pdf.py--> fichas/*.txt --converter.py--> saida/*.json --macro--> Foundry
                                                    ^
                           biblioteca.json (gerada do compêndio do usuário)

  1) Biblioteca (uma vez): macro macros/exportar_compendio.js no Foundry
     exporta "ameacas-de-arton-cdm.ameacas" e "tormenta20.magias" em JSON;
     depois: python -m t20conv.biblioteca <arquivos ou pastas> -o biblioteca.json
     (também aceita pastas geradas por "foundryvtt-cli unpack"; no chat eu
     desempacotei os LevelDB do repositório com @foundryvtt/foundryvtt-cli@1.0.3
     via node: extractPack(src, dest)).
  2) python tools/extrair_pdf.py livro.pdf --paginas 140-150 -o fichas/x.txt
     (--diagnostico mostra fonte/flags de cada trecho para calibrar)
  3) python converter.py fichas/ -o saida/ --biblioteca biblioteca.json
  4) No Foundry: macro macros/importar_atores.js -> escolher saida/_todos.json
     (ou botão direito num ator -> Import Data -> saida/<nome>.json)
  5) Ler saida/_relatorio.txt ([auto], [texto], [biblioteca], [magia], ⚠).

--------------------------------------------------------------------------------

  Espírito Médio [solo]          <- [solo]/[especial]/[lacaio]; padrão solo
  **Iniciativa** +5, **Percepção** +3, faro, visão na penumbra
  **Defesa** 24, **Fort** +17, **Ref** +11, **Von** +5, imunidade a doenças, fogo e veneno, redução de dano 5
  **Pontos de Vida** 200
  **Deslocamento** 9m (6q)
  **Pontos de Mana** 112          (opcional)
  **Corpo a Corpo** Machado de guerra +17 (1d12+16, x3) e chifres +17 (1d6+10 mais doença).
  **À Distância** ...
  **Nome da Habilidade (Execução, N PM)** texto...
  **Magias** Como um mago de 14º nível (CD 38, limite de PM 23).
  • *Bola de Fogo (Padrão, 11 PM)* texto...
  **For** 5, **Des** 1, **Con** 3, **Int** 0, **Sab** –1, **Car** –2

rótulos internos quebrados (Fort/Ref/Von/Des.../Percepção, Tesouro após
Equipamento) são colados à linha anterior; várias fichas por arquivo
separadas por linha "==="; parser é tolerante a MAIÚSCULAS (versalete do PDF).

5. CONVENÇÕES DO SISTEMA tormenta20 (levantadas de 408 NPCs do compêndio)
--------------------------------------------------------------------------------
Ator:
- type "npc". system.atributos.<for|des|con|int|sab|car>.base = valor.
- attributes.pv/pm {value,max}; attributes.movement {walk,fly,swim,climb,burrow} em m;
  attributes.defesa.base = Defesa do livro; attributes.nd = "5" (string);
  attributes.sentidos.value: escuro, faro, penumbra, cegas (+custom).
  attributes.cd: compêndio deixa 10 quase sempre (CD de magia vai no texto).
- detalhes: tipo (ani/con/esp/hum/mon/mor), raca, role (solo/special/lackey),
  resistencias (texto da linha), ataquescac/ataquesad (texto), equipamento, tesouro.
- tracos.tamanho: min/peq/med/gra/eno/col. Token: gra 2, eno 3, col 4 quadrados.
- tracos.resistencias.<tipo>: {base (RD), imunidade, vulnerabilidade}; tipos:
  acido corte eletricidade essencia fogo frio impacto luz psiquico perfuracao
  trevas perda, e "dano" (RD geral).
- tracos.ic.value (imunidade a condições): medo, atordoado, metabolismo, cansaco,
  metamorfose, veneno, caido, sentidos, movimento, ofuscado, alquebrado,
  esmorecido, frustrado, confuso, lento, fascinado, enfeiticado, mental,
  surpreendido, paralisado. Resto (ex.: "doenças") em ic.custom.
- Perícias (convenção do Oni, dominante): treinadas -> value = total do livro,
  treinado true, outros 0. Fort/Ref/Von -> value 0, outros = total.
  Chaves: acro ades atle atua cava conh cura dipl enga fort furt guer inic inti
  intu inve joga ladi luta mist nobr ofi0 perc pilo pont refl reli sobr vont.
Itens:
- arma: rolls Ataque [["1d20","",""],["luta"|"pont","",""],["17","",""]],
  Dano [["1d6+10","perfuracao",""]]; criticoM (margem), criticoX (mult.);
  proficiencia natural/simples/marcial/exotica/fogo; proposito corpo-a-corpo/
  disparo/arremesso; empunhadura leve/uma/duas; campo "ataques" quase sempre 1
  (nome "Duas Garras" com ataques=1 — semântica de ataques>1 a confirmar).
- poder: system.tipo "ability" para habilidades de ameaça; ativacao.execucao
  free/action/move/full/reaction; ativacao.custo = PM.
- magia: tipo arc/div/uni, escola (abj adv con enc evo ilu nec tra), circulo
  "1".."5", alcance short/medium/long/touch/self, duracao.units
  inst/scene/sust/round/turn/day; descrição no padrão do compêndio:
  <section class="secret">linha da ficha</section> + descrição base.
- Rolagens: tipos ataque/dano/formula. Tipos de dano especiais: curapv,
  curatpv, perda. Manobra = formula "d20+N" com nome da manobra.
Efeitos (flags.tormenta20: onuse, attack, skill, spell, self, items, custo,
aumenta, durationScene):
- Bônus condicional em ataque (Avesso à Honra): no poder, onuse+attack,
  transfer true, disabled true, changes key "dano"/"ataque" modo 2;
  margem de ameaça: "criticoM" modo 2 valor "-N".
- Bônus condicional em teste: onuse+skill, items "Vontade;Reflexos" (nomes
  de perícia separados por ;), change "roll" modo 2 (aceita "@car", "kh").
- Resistência a magia +N: idem com items "Vontade;Reflexos;Fortitude".
- Magia Acelerada: onuse+spell, change "execucao" modo 5 "livre", flag custo.
- Aprimoramentos de magia: onuse+self(+aumenta), keys dano / dano:fogo (modo 0)
  / alcance / alvo / duracao / area / execucao / condicao / resistencia.
- Buff de magia/poder ativo: durationScene true, transfer false, disabled false.
- Passivos sempre ligados: transfer true, disabled false.
- Chaves de ator usadas: system.attributes.defesa.bonus, system.atributos.X.value,
  system.pericias.X.bonus, system.modificadores.ataque.{geral,cac,ad},
  system.modificadores.dano.{geral,cac,ad,mag}, system.tracos.resistencias.X.bonus,
  system.attributes.movement.X (modo 5 para voo concedido).

  ficava só "1d10" e o tipo se perdia). (A CONFIRMAR no Foundry.)
- Tipos de dano canônicos por regra: mordida perfuração, garra corte, chifres
  perfuração, pancada impacto, cauda impacto, ferrão perfuração, tentáculo impacto…

  da biblioteca são descartados para não somar em dobro.
- "(já contabilizado)": trecho ignorado (evita somar Int 2x no Arcano de Batalha).
- Bônus permanentes ("recebe +2 em Furtividade") NÃO viram efeito: os números
  do livro já os incluem.
- "mais doença" num ataque: texto da habilidade Doença copiado na arma + chatFlavor.
- Ataque concedido por magia (mordida da Transformação em Dragão) vira arma extra.
- Poder com texto idêntico a um configurado no compêndio é reaproveitado
  (só quando as regras não automatizam nada e o caso não está "decidido").

##### ARQUIVO: converter.py #####
"""Converte fichas de ameaças de Tormenta20 (texto) em atores JSON para o Foundry VTT.

Uso:
  python converter.py fichas/ -o saida/ [--biblioteca biblioteca.json] [--img caminho]

Entrada: arquivos .txt (uma ou várias fichas por arquivo; separe fichas com uma linha "===").
Saída:
  saida/<nome>.json        um ator por arquivo (Foundry: botão direito no ator > Import Data)
  saida/_todos.json        todos os atores numa lista (macro importar_atores.js, em lote)
  saida/_relatorio.txt     o que foi automatizado e o que precisa de revisão
"""
from __future__ import annotations

import argparse
import json
import re
import sys
from pathlib import Path

from t20conv.biblioteca import Biblioteca
from t20conv.construtor import Construtor
from t20conv.parser import norm, parse


def fichas_em(caminhos: list[Path]):
    for c in caminhos:
        arqs = sorted(c.glob("*.txt")) if c.is_dir() else [c]
        for a in arqs:
            for bloco in re.split(r"^\s*===+\s*$", a.read_text(encoding="utf-8"), flags=re.M):
                if bloco.strip():
                    yield a.name, bloco


def main():
    ap = argparse.ArgumentParser(description=__doc__, formatter_class=argparse.RawDescriptionHelpFormatter)
    ap.add_argument("entradas", nargs="+", type=Path)
    ap.add_argument("-o", "--saida", type=Path, default=Path("saida"))
    ap.add_argument("--biblioteca", default="biblioteca.json",
                    help="índice gerado por 'python -m t20conv.biblioteca' (opcional)")
    ap.add_argument("--img", default="icons/svg/mystery-man.svg", help="imagem padrão de ator/token")
    a = ap.parse_args()

    bib = Biblioteca.carregar(a.biblioteca)
    if not bib.poderes:
        print(f"(sem biblioteca em '{a.biblioteca}': seguindo só com as regras)", file=sys.stderr)
    cons = Construtor(bib, a.img)
    a.saida.mkdir(parents=True, exist_ok=True)
    todos, linhas = [], []
    for origem, bloco in fichas_em(a.entradas):
        ficha = parse(bloco)
        ator, rel = cons.ator(ficha)
        todos.append(ator)
        nome_arq = re.sub(r"[^a-z0-9]+", "-", norm(ator["name"])).strip("-") or "ator"
        (a.saida / f"{nome_arq}.json").write_text(json.dumps(ator, ensure_ascii=False, indent=1), encoding="utf-8")
        linhas.append(f"■ {ator['name']} (ND {ficha['nd']})  ← {origem}")
        linhas += [f"   {i}" for i in rel["itens"]]
        linhas += [f"   ⚠ {w}" for w in rel["avisos"]]
        linhas.append("")
    (a.saida / "_todos.json").write_text(json.dumps(todos, ensure_ascii=False), encoding="utf-8")
    rel_txt = "\n".join(linhas)
    (a.saida / "_relatorio.txt").write_text(rel_txt, encoding="utf-8")
    print(rel_txt)
    print(f"{len(todos)} ator(es) em {a.saida}/")


if __name__ == "__main__":
    main()

"""Texto de ficha de ameaça (Tormenta20) -> dicionário estruturado ("ficha").

Formato de entrada (o que o extrator de PDF gera, e o que dá para colar à mão):
  - 1ª linha: nome; em seguida "ND x" e a linha de tipo/tamanho
    (opcionalmente com [solo] / [especial] / [lacaio]).
  - Rótulos em negrito ficam entre **...** (ex.: **Iniciativa** +5).
  - Magias em lista começam com "•" e o nome pode estar em *itálico*.
  - "---" separa blocos (opcional, é ignorado).
  - Linhas quebradas no meio são juntadas automaticamente (inclusive hifenização).
"""
from __future__ import annotations

import re
import unicodedata

# ---------------------------------------------------------------- utilidades

def sem_acento(s: str) -> str:
    return "".join(c for c in unicodedata.normalize("NFD", s) if unicodedata.category(c) != "Mn")


def norm(s: str) -> str:
    return re.sub(r"\s+", " ", sem_acento(s).lower()).strip()


def num(s: str) -> int:
    return int(s.replace("–", "-").replace("−", "-").replace("+", "").strip())


def titulo(s: str) -> str:
    """'DRAGÃO DE FOGO' -> 'Dragão de Fogo' (preposições/artigos minúsculos, exceto no início)."""
    if not s.isupper():
        return s
    pal = s.title().split(" ")
    menores = {"de", "da", "do", "das", "dos", "e", "o", "a", "os", "as", "em", "no", "na"}
    return " ".join(w.lower() if i and norm(w) in menores else w for i, w in enumerate(pal))


def limpa_md(s: str) -> str:
    return s.replace("**", "").replace("*", "").strip()


def dividir_topo(s: str, seps=(", ", " e ")) -> list[str]:
    """Divide por separadores apenas fora de parênteses."""
    partes, nivel, atual, i = [], 0, "", 0
    while i < len(s):
        c = s[i]
        if c == "(":
            nivel += 1
        elif c == ")":
            nivel -= 1
        if nivel == 0:
            hit = next((sp for sp in seps if s.startswith(sp, i)), None)
            if hit:
                partes.append(atual)
                atual = ""
                i += len(hit)
                continue
        atual += c
        i += 1
    partes.append(atual)
    return [p.strip() for p in partes if p.strip()]

    n = norm(item)
    return next((v for k, v in IC if k in n), None)


def tipo_dano(palavra: str) -> str | None:
    return TIPOS_DANO.get(norm(palavra))


# ---------------------------------------------------------------- linhas lógicas

def linhas_logicas(texto: str) -> list[str]:
    out: list[str] = []
    for bruta in texto.splitlines():
        ln = bruta.strip()
        if not ln:
            continue
        novo = ln.startswith(("**", "•", "---")) or not out or len(out) < 3 and "**" not in ln
        # rótulos que só aparecem no meio de uma linha (quebra de linha do PDF): junta à anterior
        if out and (re.match(r"^\*\*\s*(Fort|Ref|Von|Des|Con|Int|Sab|Car|Percep[çc][ãa]o)\b", ln, re.I)
                    or re.match(r"^\*\*\s*Tesouro", ln, re.I) and re.match(r"^\*\*\s*Equipamento", out[-1], re.I)):
            novo = False
        if novo or out[-1] == "---":
            out.append(ln)
            continue
        ant = out[-1]
        if re.search(r"[a-zà-ú]-$", ant) and re.match(r"[a-zà-ú]", ln):
            out[-1] = ant[:-1] + ln          # hifenização "macha-" + "do"
        else:
            out[-1] = ant + " " + ln
    return [l for l in out if l != "---"]


def cabecalho_execucao(paren: str) -> dict:
    """'(Reação, 23 PM)' / '(Livre, +4 PM)' / '(Padrão, 10 PM, sustentada)'."""
    r = {"execucao": "", "custo": 0, "sustentada": False, "especial": []}
    for parte in [p.strip() for p in paren.split(",")]:
        n = norm(parte)
        m = re.match(r"\+?(\d+)\s*pm$", n)
        if m:
            r["custo"] = int(m.group(1))
        elif n in EXECUCOES:
            r["execucao"] = EXECUCOES[n]
        elif n.startswith("sustentad"):
            r["sustentada"] = True
        elif n:
            r["especial"].append(parte)
    return r


def separa_nome_paren(s: str):
    """'Ataque Pesado (Livre)' -> ('Ataque Pesado', 'Livre'); sem parênteses -> (s, None)."""
    m = re.match(r"^(.*?)\s*\(([^()]*)\)\s*$", s)
    if m and (re.search(r"pm", norm(m.group(2))) or norm(m.group(2).split(",")[0]) in EXECUCOES):
        return m.group(1).strip(), m.group(2)
    return s.strip(), None


# ---------------------------------------------------------------- partes da ficha

def parse_ataques(txt: str, categoria: str, avisos: list) -> list[dict]:
    ataques = []
    for peca in dividir_topo(txt.rstrip(". ")):
        m = re.match(r"^(.+?)\s+([+\-–]\d+)\s*\((.*)\)$", peca)
        if not m:
            avisos.append(f"ataque não entendido: '{peca}'")
            continue
        nome, bonus, dentro = m.group(1).strip(), num(m.group(2)), m.group(3)
        qtd = 1
        pal = nome.split(" ", 1)
        if len(pal) == 2 and norm(pal[0]) in NUMERAIS:
            qtd, nome = NUMERAIS[norm(pal[0])], pal[1]
            if nome.endswith("s") and not nome.endswith("ões"):
                nome = nome[:-1]                     # "garras" -> "garra"
        nome = nome[0].upper() + nome[1:]
        at = {"nome": nome, "qtd": qtd, "bonus": bonus, "categoria": categoria,
              "dano": "", "tipo": None, "criticoM": 20, "criticoX": 2,
              "dano_extra": [], "extras": [], "texto": peca}
        partes = dividir_topo(dentro, seps=(", ",))
        dm = re.match(rf"^({DADO})(?:\s+(\w+))?(.*)$", partes[0])
        if dm:
            at["dano"] = dm.group(1).replace(" ", "").replace("–", "-")
            resto = dm.group(3).strip()
            if dm.group(2):
                td = tipo_dano(dm.group(2))
                if td:
                    at["tipo"] = td
                else:
                    resto = (dm.group(2) + " " + resto).strip()
            for mais in re.split(r"\s*\bmais\b\s*", resto):
                if not mais:
                    continue
                em = re.match(rf"^({DADO})\s+(?:de\s+)?(\w+)", mais)
                if em and tipo_dano(em.group(2)):
                    at["dano_extra"].append((em.group(1).replace(" ", ""), tipo_dano(em.group(2))))
                else:
                    at["extras"].append(mais.strip())
        else:
            avisos.append(f"dano não entendido em '{peca}'")
        for p in partes[1:]:
            cm = re.match(r"^(\d+)?\s*/?\s*(?:x(\d+))?$", p.strip())
            if cm and (cm.group(1) or cm.group(2)):
                if cm.group(1):
                    at["criticoM"] = int(cm.group(1))
                if cm.group(2):
                    at["criticoX"] = int(cm.group(2))
            else:
                at["extras"].append(p)
        ataques.append(at)
    return ataques


def parse_resistencias(txt: str) -> dict:
    r = {"imunidades": [], "ic": [], "ic_custom": [], "reducoes": {}, "vulnerab": [], "outros": []}
    if not txt:
        return r
    chaves = ("imunidade", "reducao", "resistencia", "vulnerabilidade", "cura acelerada")
    clausulas: list[str] = []
    for ch in [c.strip() for c in txt.split(",")]:
        if not clausulas or norm(ch).startswith(chaves):
            clausulas.append(ch)
        else:
            clausulas[-1] += ", " + ch
    for c in clausulas:
        n = norm(c)
        if n.startswith("imunidade"):
            lista = re.sub(r"^imunidades? (?:a|ao|aos|as|à|às)\s+", "", c, flags=re.I)
            for item in dividir_topo(lista, seps=(", ", " e ")):
                td = tipo_dano(item)
                if td:
                    r["imunidades"].append(td)
                elif condicao_ic(item):
                    r["ic"].append(condicao_ic(item))
                else:
                    r["ic_custom"].append(item)
        elif n.startswith("reducao de"):
            m = re.match(r"reducao de (.+?) (\d+)(.*)$", n)
            if m:
                for t in dividir_topo(m.group(1), seps=(", ", " e ")):
                    td = tipo_dano(t)
                    if td:
                        r["reducoes"][td] = int(m.group(2))
                    else:
                        r["outros"].append(c)
            else:
                r["outros"].append(c)
        elif n.startswith("vulnerabilidade"):
            lista = re.sub(r"^vulnerabilidades? (?:a|ao|aos)\s+", "", n)
            for item in dividir_topo(lista, seps=(", ", " e ")):
                td = tipo_dano(item)
                (r["vulnerab"] if td else r["outros"]).append(td or c)
        else:
            r["outros"].append(c)
    return r


def parse_deslocamento(txt: str) -> dict:
    d = {"walk": 0, "fly": 0, "swim": 0, "climb": 0, "burrow": 0}
    nomes = {"voo": "fly", "natacao": "swim", "escalar": "climb", "escalada": "climb",
             "escavar": "burrow", "escavacao": "burrow"}
    for parte in dividir_topo(txt, seps=(", ",)):
        n = norm(parte)
        m = re.match(r"(?:(\w+)\s+)?(\d+(?:,\d+)?)\s*m", n)
        if not m:
            continue
        val = float(m.group(2).replace(",", "."))
        val = int(val) if val.is_integer() else val
        d[nomes.get(m.group(1), "walk") if m.group(1) else "walk"] = val
    return d


# ---------------------------------------------------------------- principal

def parse(texto: str) -> dict:
    linhas = linhas_logicas(texto)
    avisos: list[str] = []
    f: dict = {"nome": "", "nd": "", "tipo": "", "raca": "", "tamanho": "med", "papel": "",
               "iniciativa": 0, "percepcao": 0, "sentidos": [], "sentidos_custom": [],
               "defesa": 10, "fort": 0, "ref": 0, "von": 0, "resist_texto": "",
               "resist": parse_resistencias(""), "pv": 0, "pm": 0,
               "deslocamento": parse_deslocamento(""), "ataques": [],
               "ataques_texto": {"cac": "", "ad": ""}, "habilidades": [],
               "magias_info": None, "magias": [], "atributos": {}, "pericias": {},
               "equipamento": "", "tesouro": "", "avisos": avisos}

    # ---- cabeçalho (antes do primeiro rótulo em negrito)
    i = 0
    cab = []
    while i < len(linhas) and not linhas[i].startswith("**"):
        cab.append(linhas[i])
        i += 1
    for c in cab:
        m = re.search(r"\bND\s*([\d/]+)", c)
        if m:
            f["nd"] = m.group(1)
            c = c.replace(m.group(0), "").strip()
            if not c:
                continue
        nc = norm(limpa_md(c))
        tam = next((v for k, v in TAMANHOS.items() if re.search(rf"\b{k}\b", nc)), None)
        if tam and f["nome"]:
            f["tamanho"] = tam
            f["tipo"] = next((v for k, v in TIPOS.items() if nc.startswith(k)), "")
            if not f["tipo"]:
                avisos.append(f"tipo de criatura não reconhecido: '{c}'")
            rm = re.search(r"\(([^)]+)\)", c)
            if rm:
                f["raca"] = rm.group(1).strip()
            pm_ = re.search(r"\[(\w+)\]", nc)
            if pm_:
                f["papel"] = PAPEIS.get(pm_.group(1), "")
        elif not f["nome"]:
            f["nome"] = limpa_md(c)
    # Title() deixa "Dragão Celestial Jovem" ok; conectivos minúsculos:
    f["nome"] = titulo(f["nome"])

    magia_atual = False
    for ln in linhas[i:]:
        if ln.startswith("•"):
            if not magia_atual:
                avisos.append(f"item de lista fora de Magias: '{ln[:50]}'")
                continue
            corpo = limpa_md(ln.lstrip("• "))
            corpo = re.sub(r"[^\w\s()\-–,.;:'\"“”!?/+%ºª°]", "", corpo).strip()
            m = re.match(r"^(.+?)\s*\(([^()]*)\)\s*(.*)$", corpo)
            if not m:
                avisos.append(f"magia não entendida: '{corpo[:60]}'")
                continue
            ex = cabecalho_execucao(m.group(2))
            f["magias"].append({"nome": m.group(1).strip(), **ex, "paren": m.group(2).strip(),
                                "texto": m.group(3).strip()})
            continue

        mrot = re.match(r"^\*\*(.+?)\*\*\s*(.*)$", ln)
        if not mrot:
            avisos.append(f"linha ignorada: '{ln[:60]}'")
            continue
        rot, resto = mrot.group(1).strip(), mrot.group(2).strip()
        nr = norm(rot)
        magia_atual = False

        if nr == "iniciativa":
            plano = limpa_md(ln)
            m = re.search(r"Iniciativa\s*([+\-–]\d+)", plano, re.I)
            f["iniciativa"] = num(m.group(1)) if m else 0
            m = re.search(r"Percep[çcÇC][ãaÃA]o\s*([+\-–]\d+)\s*,?\s*(.*)$", plano, re.I)
            if m:
                f["percepcao"] = num(m.group(1))
                for s in dividir_topo(m.group(2).rstrip("."), seps=(", ",)):
                    k = SENTIDOS.get(norm(s))
                    (f["sentidos"] if k else f["sentidos_custom"]).append(k or s)
        elif nr == "defesa":
            plano = limpa_md(ln)
            m = re.match(r"Defesa\s*(\d+)\s*,\s*Fort\s*([+\-–]\d+)\s*,\s*Ref\s*([+\-–]\d+)\s*,"
                         r"\s*Von\s*([+\-–]\d+)\s*,?\s*(.*)$", plano, re.I)
            if m:
                f["defesa"] = int(m.group(1))
                f["fort"], f["ref"], f["von"] = (num(m.group(k)) for k in (2, 3, 4))
                f["resist_texto"] = m.group(5).rstrip(". ")
                f["resist"] = parse_resistencias(f["resist_texto"])
            else:
                avisos.append(f"linha de Defesa não entendida: '{plano}'")
        elif nr == "pontos de vida":
            f["pv"] = int(re.match(r"\d+", resto).group(0))
        elif nr == "pontos de mana":
            f["pm"] = int(re.match(r"\d+", resto).group(0))
        elif nr == "deslocamento":
            f["deslocamento"] = parse_deslocamento(resto)
        elif nr in ("corpo a corpo", "a distancia"):
            cat = "cac" if nr == "corpo a corpo" else "ad"
            f["ataques_texto"][cat] = limpa_md(resto)
            f["ataques"] += parse_ataques(limpa_md(resto), cat, avisos)
        elif nr == "magias":
            info = {"texto": limpa_md(resto), "classe": "", "nivel": 0, "cd": None, "limite": None}
            m = re.search(r"como um[a]? (\w+)", norm(resto))
            if m:
                info["classe"] = m.group(1)
            for chave, rx in (("nivel", r"(\d+)\s*[º°o]\s*nivel"), ("cd", r"cd\s*(\d+)"),
                              ("limite", r"limite de pm\s*(\d+)")):
                m = re.search(rx, norm(resto))
                if m:
                    info[chave] = int(m.group(1))
            f["magias_info"] = info
            magia_atual = True
        elif nr == "for":
            for a, v in re.findall(r"\b(For|Des|Con|Int|Sab|Car)\s+([+\-–]?\d+|—|–)", limpa_md(ln), re.I):
                f["atributos"][a.lower()] = num(v) if re.search(r"\d", v) else 0
        elif nr == "pericias":
            for p in dividir_topo(limpa_md(resto).rstrip("."), seps=(", ",)):
                m = re.match(r"^(.+?)\s*([+\-–]\d+)$", p)
                if not m:
                    avisos.append(f"perícia não entendida: '{p}'")
                    continue
                nome = norm(re.sub(r"\(.*?\)", "", m.group(1)))
                k = PERICIAS.get(nome)
                if k:
                    f["pericias"][k] = num(m.group(2))
                else:
                    avisos.append(f"perícia desconhecida: '{p}'")
        elif nr in ("equipamento", "tesouro"):
            plano = re.split(r"\*\*Tesouro\*\*", ln, flags=re.I)
            if nr == "equipamento":
                f["equipamento"] = limpa_md(re.sub(r"^\*\*Equipamento\*\*", "", plano[0], flags=re.I)).rstrip(". ")
                if len(plano) > 1:
                    f["tesouro"] = limpa_md(plano[1]).rstrip(". ")
            else:
                f["tesouro"] = limpa_md(resto).rstrip(". ")
        else:
            nome, paren = separa_nome_paren(rot)
            if paren is None and resto.startswith("("):
                m = re.match(r"^\(([^()]*)\)\s*(.*)$", resto)
                if m and separa_nome_paren(f"x ({m.group(1)})")[1] is not None:
                    paren, resto = m.group(1), m.group(2)
            ex = cabecalho_execucao(paren) if paren else cabecalho_execucao("")
            if nome.isupper() and len(nome) > 3:
                nome = titulo(nome)
            f["habilidades"].append({"nome": nome, **ex, "texto": limpa_md(resto)})

    if not f["atributos"]:
        avisos.append("atributos não encontrados")
    if not f["papel"]:
        f["papel"] = "solo"
        avisos.append("papel (solo/especial/lacaio) não indicado; usando 'solo'")
    return f

def limpa_formula(f: str) -> str:
    return re.sub(r"\s+", "", f.replace("–", "-"))


# ---------------------------------------------------------------- fábricas

def efeito(nome: str, changes: list, *, onuse=False, attack=False, skill=False, spell=False,
           self_=False, items="", custo="", transfer=True, disabled=True, rounds=None,
           cena=False, aumenta=False) -> dict:
    e = copy.deepcopy(ESQ["efeito"])
    e["_id"] = novo_id()
    e["name"] = nome
    e["changes"] = [{"key": k, "mode": m, "value": str(v), "priority": 0} for k, m, v in changes]
    e["transfer"], e["disabled"] = transfer, disabled
    e["duration"]["rounds"] = rounds
    e["flags"]["tormenta20"].update(onuse=onuse, attack=attack, skill=skill, spell=spell,
                                    self=self_, items=items, custo=str(custo or ""),
                                    durationScene=cena, aumenta=aumenta)
    return e


def rolagem(nome: str, tipo: str, partes: list, i: int) -> dict:
    return {"name": nome, "key": f"{tipo}{i}", "type": tipo,
            "parts": [list(p) for p in partes], "versatil": ""}

def rolagens_de_dano(texto: str) -> list[dict]:
    """'XdY pontos de dano de T [mais XdY pontos de dano de U]' -> rolagens (ignora '+XdY' = bônus)."""
    rx = re.compile(rf"(?<![+\d])({DADO})\s+(?:pontos\s+)?de\s+dano(?:\s+de\s+([a-zà-ú]+))?", re.I)
    grupos: list[list] = []
    fim_ant = None
    for m in rx.finditer(texto):
        parte = [limpa_formula(m.group(1)), tipo_dano(m.group(2)) if m.group(2) else "", ""]
        entre = texto[fim_ant:m.start()] if fim_ant is not None else ""
        if grupos and re.fullmatch(r"\s*(?:mais|e|\+)\s*", entre):
            grupos[-1][1].append(parte)
        else:
            antes = norm(texto[max(0, m.start() - 90):m.start()])
            nome = "Sopro" if "sopr" in antes else "Dano"
            grupos.append([nome, [parte]])
        fim_ant = m.end()
    for m in re.finditer(rf"\b(?:cura|curam|recupera|recuperam)\s+({DADO})(?:\s*(?:PV|pontos de vida))?", texto, re.I):
        grupos.append(["Cura", [[limpa_formula(m.group(1)), "curapv", ""]]])
    for m in re.finditer(rf"\bperdem?\s+({DADO})\s*(?:PV|pontos de vida)", texto, re.I):
        grupos.append(["Perda de PV", [[limpa_formula(m.group(1)), "perda", ""]]])
    for m in re.finditer(rf"({DADO})\s*(?:PV|pontos de vida) tempor[aá]rios", texto, re.I):
        grupos.append(["PV Temporário", [[limpa_formula(m.group(1)), "curatpv", ""]]])
    vistos, saida = {}, []
    for nome, partes in grupos:
        vistos[nome] = vistos.get(nome, 0) + 1
        rot = nome if vistos[nome] == 1 else f"{nome} ({vistos[nome]})"
        saida.append(rolagem(rot, "dano", partes, len(saida)))
    return saida


MANOBRAS = ("agarrar", "derrubar", "empurrar", "desarmar", "quebrar", "atropelar", "fintar")


def rolagem_teste(texto: str, nome_hab: str = "") -> list[dict]:
    """'manobra derrubar ou empurrar ... (teste +19)' -> formula d20+19."""
    out = []
    manobra_nome = next((mb.capitalize() for mb in MANOBRAS if mb in norm(nome_hab)), None)
    for m in re.finditer(r"\(teste\s*([+\-–]\d+)\)", texto):
        antes = norm(texto[max(0, m.start() - 160):m.start()])
        mm = re.findall(r"manobras? (\w+)(?: ou (\w+))?", antes)
        nome = manobra_nome or "Teste"
        if mm:
            nome = " ou ".join(x.capitalize() for x in mm[-1] if x)
        out.append(rolagem(nome, "formula", [[f"d20+{int(m.group(1).replace('–', '-').lstrip('+'))}", "", ""]], len(out)))
    return out


def resistencia(texto: str) -> str:
    m = re.search(r"\((Fort|Ref|Von|Fortitude|Reflexos|Vontade)\b(?:\s+CD\s+(\d+))?\s*([^)]*)\)", texto)
    if not m:
        return ""
    txt = f"{RESIST[norm(m.group(1))]} {m.group(3).strip()}".strip()
    return txt + (f" (CD {m.group(2)})" if m.group(2) else "")


def alcance(texto: str) -> str:
    m = re.search(r"alcance (curto|m[eé]dio|longo)", texto)
    return ALCANCES[norm(m.group(1))] if m else ""


def lista_alvos(lista: str) -> list[str]:
    return [x for x in dividir_topo(lista, seps=(", ", " e ")) if x]


def mudancas_buff(texto: str, notas: list) -> list[tuple]:
    """Bônus numéricos que um buff concede -> changes (chave, modo, valor)."""
    ch = []
    t = texto
    for m in re.finditer(r"\+(\d+) (?:na|em) Defesa", t):
        ch.append(("system.attributes.defesa.bonus", 2, m.group(1)))
    for m in re.finditer(r"\+(\d+) em ((?:[A-ZÀ-Ú][\wçãéíóú]+(?:,\s*| e )?)+)", t):
        for alvo in lista_alvos(m.group(2)):
            n = norm(alvo)
            if n in ATRIBUTOS:
                ch.append((f"system.atributos.{ATRIBUTOS[n]}.value", 2, m.group(1)))
            elif n in PERICIAS:
                ch.append((f"system.pericias.{PERICIAS[n]}.bonus", 2, m.group(1)))
    for m in re.finditer(r"(?<![\dd])\+(\d+) (?:em|nos) testes de (ataque|resist[eê]ncia)"
                         r"( e (?:em |nas )?rolagens de dano)?([^.;]{0,40})", t):
        if norm(m.group(2)) == "ataque":
            cauda = norm(m.group(4) or "")
            alvo = "cac" if "corpo a corpo" in cauda else "ad" if "distancia" in cauda else "geral"
            ch.append((f"system.modificadores.ataque.{alvo}", 2, m.group(1)))
            if m.group(3):
                ch.append((f"system.modificadores.dano.{alvo}", 2, m.group(1)))
        else:
            ch += [(f"system.pericias.{k}.bonus", 2, m.group(1)) for k in ("fort", "refl", "vont")]
    for m in re.finditer(r"(?<![\dd])\+(\d+) (?:em|nas) rolagens de dano", t):
        ch.append(("system.modificadores.dano.geral", 2, m.group(1)))
    for m in re.finditer(r"redu[cç][aã]o de ([a-zà-ú]+(?:(?:, | e )[a-zà-ú]+)*) (\d+)", t):
        for tp in lista_alvos(m.group(1)):
            td = tipo_dano(tp)
            if td:
                ch.append((f"system.tracos.resistencias.{td}.bonus", 2, m.group(2)))
    for m in re.finditer(r"deslocamento de (voo|nata[cç][aã]o|escalada|escalar) (\d+)\s*m", t):
        k = {"voo": "fly", "natacao": "swim", "escalada": "climb", "escalar": "climb"}[norm(m.group(1))]
        ch.append((f"system.attributes.movement.{k}", 5, m.group(2)))
    if re.search(r"resist[eê]ncia a magia \+\d+", t):
        notas.append("resistência a magia do buff não tem campo próprio; aplique manualmente")
    if "camuflagem" in norm(t):
        notas.append("camuflagem não é automatizável (só texto)")
    return ch


def duracao_buff(texto: str) -> tuple[int | None, bool]:
    n = norm(texto)
    if re.search(r"por (?:1|uma) (?:rodada|turno)|ate o (?:inicio|fim) de seu proximo turno", n):
        return 1, False
    return None, True


def bonus_ataque(nome: str, texto: str, notas: list) -> list[dict]:
    """Bônus condicionais aplicados a ataques (ex.: Avesso à Honra)."""
    ch = []
    for m in re.finditer(rf"(?<![\dd])\+({DADO}|\d+)\s+(?:pontos\s+de\s+dano|de\s+dano|dano)(?:\s+de\s+([a-zà-ú]+))?", texto):
        f, tp = limpa_formula(m.group(1)), tipo_dano(m.group(2)) if m.group(2) else None
        if tp and tp != "dano":
            f = f"{f}[{tp}]"
        ch.append(("dano", 2, f))
    for m in re.finditer(r"(?<![\dd])\+(\d+) (?:em|n[oa]s?) (?:seus )?(?:testes? de ataque|ataques?)( e (?:em |nas )?rolage(?:m|ns) de dano)?", texto):
        ch.append(("ataque", 2, m.group(1)))
        if m.group(2):
            ch.append(("dano", 2, m.group(1)))
    for m in re.finditer(rf"(?<![\dd])\+({DADO}|\d+) (?:em|n[ao]s?) rolage(?:m|ns) de dano", texto):
        ch.append(("dano", 2, limpa_formula(m.group(1))))
    for m in re.finditer(r"\+(\d+) na margem de amea[cç]a", texto):
        ch.append(("criticoM", 2, f"-{m.group(1)}"))
    if not ch:
        return []
    return [efeito(f"{nome}: {texto}", ch, onuse=True, attack=True)]


def bonus_testes(nome: str, texto: str) -> list[dict]:
    """'+N em testes de Percepção e Vontade quando...' / 'resistência a magia +N'."""
    out = []
    sa = re.search(r"soma (?:seu|sua) (Força|Destreza|Constituição|Inteligência|Sabedoria|Carisma) "
                   r"(?:em|nos|a) (?:um )?testes? de ((?:[\wÀ-ú]+(?:,\s*| e | ou )?)+)", texto)
    if sa:
        attr = ATRIBUTOS[norm(sa.group(1))]
        pers = [NOME_PERICIA[PERICIAS[norm(a)]] for a in dividir_topo(sa.group(2), seps=(", ", " e ", " ou "))
                if norm(a) in PERICIAS]
        out.append(efeito(f"{nome}: {texto}", [("roll", 2, f"@{attr}")], onuse=True, skill=True,
                          items=";".join(pers)))
    m = re.search(r"resist[eê]ncia a magia \+(\d+)", texto)
    if m:
        out.append(efeito(f"{nome}: resistência a magia +{m.group(1)}", [("roll", 2, m.group(1))],
                          onuse=True, skill=True, items="Vontade;Reflexos;Fortitude"))
    for m in re.finditer(r"\+(\d+) em (?:testes de )?((?:[A-ZÀ-Ú][\wçãéíóú]+(?:,\s*| e )?)+)", texto):
        pers = [NOME_PERICIA[PERICIAS[norm(a)]] for a in lista_alvos(m.group(2)) if norm(a) in PERICIAS]
        if pers:
            out.append(efeito(f"{nome}: {texto}", [("roll", 2, m.group(1))], onuse=True, skill=True,
                              items=";".join(pers)))
    return out


# ---------------------------------------------------------------- habilidade (poder)

def automatizar_habilidade(h: dict) -> dict:
    """h = {nome, execucao, custo, sustentada, texto} -> {rolls, effects, resistencia, alcance, notas}."""
    nome, txt = h["nome"], h["texto"]
    n = norm(txt)
    notas: list[str] = []
    r = {"rolls": [], "effects": [], "resistencia": resistencia(txt), "alcance": alcance(txt),
         "notas": notas, "decidido": False}

    if "ja contabilizad" in n:
        # tira as orações marcadas como já somadas na ficha e analisa o resto
        resto = re.sub(r"[^.;]*?\((?:j[aá] )?contabilizad[oa]s?\)", "", txt, flags=re.I)
        resto = re.sub(r"^\s*(?:e|,)\s*", "", resto).strip(" .,;")
        notas.append("trecho 'já contabilizado' ignorado para não somar duas vezes")
        if len(norm(resto)) < 12:
            r["decidido"] = True
            return r
        txt, n = resto, norm(resto)

    # Execução acelerada (Magia Acelerada e afins)
    if re.search(r"muda a execu[cç][aã]o (?:dela|dele|da magia|de uma magia)? ?para livre", txt):
        r["effects"].append(efeito(nome, [("execucao", 5, "livre")], onuse=True, spell=True,
                                   custo=h.get("custo") or ""))
        return r

    r["rolls"] = rolagens_de_dano(txt) + rolagem_teste(txt, nome)

    condicional = bool(CONDICIONAL.search(n))
    com_duracao = bool(DURACAO.search(n))
    sobre_ataque = re.search(r"\bataques?\b|\bacert", n)

    if sobre_ataque and not com_duracao:
        r["effects"] += bonus_ataque(nome, txt, notas)

    if not r["effects"]:
        r["effects"] += bonus_testes(nome, txt) if (condicional or "resistencia a magia" in n) and not com_duracao else []

    if not r["effects"] and "recebe" in n and com_duracao:
        ch = mudancas_buff(txt, notas)
        if ch:
            rounds, cena = duracao_buff(txt)
            if h.get("execucao") and not condicional:
                # usada ativamente: aplica ao usar (convenção dos buffs de magia/poder)
                r["effects"].append(efeito(nome, ch, transfer=False, disabled=False, rounds=rounds, cena=cena))
            else:
                # gatilho: efeito alternável no ator
                r["effects"].append(efeito(f"{nome} (ativo)", ch, transfer=True, disabled=True, rounds=rounds))

    if not r["rolls"] and not r["effects"]:
        if not condicional and re.search(r"\+\d+ em|\+\d+ na", txt):
            notas.append("bônus permanente: já está somado nos números da ficha")
            r["decidido"] = True
        else:
            notas.append("sem automação (só texto)")
    return r


# ---------------------------------------------------------------- magia

def automatizar_magia(m: dict) -> dict:
    txt = m["texto"]
    notas: list[str] = []
    r = {"rolls": rolagens_de_dano(txt) + rolagem_teste(txt), "effects": [], "notas": notas,
         "resistencia": "", "alcance": alcance(txt), "ataques_extras": []}
    mr = re.search(r"\((Fort|Ref|Von)\w*\s+([^)]*)\)", txt)
    if mr:
        r["resistencia"] = f"{RESIST[norm(mr.group(1))]} {mr.group(2).strip()}"
    if "recebe" in norm(txt):
        ch = mudancas_buff(txt, notas)
        if ch:
            rounds, cena = duracao_buff(txt)
            r["effects"].append(efeito(m["nome"], ch, transfer=False, disabled=False,
                                       rounds=rounds, cena=cena))
    # ataque concedido pela magia: "ataque de mordida (ataque +30, dano 1d6+15, 19/x3)"
    for a in re.finditer(r"ataque de (\w+) \(ataque ([+\-–]\d+), dano ([^,)]+)(?:,\s*([^)]+))?\)", txt):
        r["ataques_extras"].append({"nome": a.group(1), "bonus": int(a.group(2).replace("–", "-")),
                                    "dano": limpa_formula(a.group(3)), "crit": a.group(4) or ""})
    if not r["rolls"] and not r["effects"]:
        notas.append("sem automação (só texto)")
    return r

def p(txt: str) -> str:
    return f"<p>{html.escape(txt, quote=False)}</p>"


def singular(n: str) -> str:
    n = norm(n)
    return n[:-1] if n.endswith("s") and n[:-1] in DANO_CANONICO | {k: 0 for k in NATURAIS} else n


class Construtor:
    def __init__(self, bib: Biblioteca, img_padrao: str = "icons/svg/mystery-man.svg"):
        self.bib = bib
        self.img_padrao = img_padrao

    # ------------------------------------------------------------ itens
    def _item(self, tipo: str, nome: str) -> dict:
        it = copy.deepcopy(ESQ[tipo])
        it["_id"] = novo_id()
        it["name"] = nome
        return it

    def arma(self, at: dict, f: dict, rel: dict) -> dict:
        nome_base = at["nome"]
        nome = nome_base if at["qtd"] == 1 else f"{NUMERAL_TXT.get(at['qtd'], at['qtd'])} {nome_base}s"
        it = self._item("arma", nome)
        x = it["system"]
        chave = singular(nome_base)
        lib = self.bib.arma(nome_base) or self.bib.arma(chave) or self.bib.arma(nome) or {}
        tipo = at["tipo"] or DANO_CANONICO.get(chave) or DANO_CANONICO.get(norm(nome_base))
        if not tipo and lib.get("tipos"):
            tipo = max(lib["tipos"], key=lib["tipos"].get)
            rel["avisos"].append(f"{nome}: tipo de dano '{tipo}' veio da biblioteca (conferir)")
        if not tipo:
            tipo = "impacto"
            rel["avisos"].append(f"{nome}: tipo de dano desconhecido, usei 'impacto'")
        natural = chave in NATURAIS or norm(nome_base) in NATURAIS
        if lib.get("img") and lib["img"] != "icons/svg/item-bag.svg":
            it["img"] = lib["img"]
        elif natural:
            it["img"] = f"systems/tormenta20/icons/poderes/ameacas/{chave}.webp"
        x["proficiencia"] = "natural" if natural else (lib.get("proficiencia") or "simples")
        x["proposito"] = ("corpo-a-corpo" if at["categoria"] == "cac"
                          else (lib.get("proposito") if lib.get("proposito") not in (None, "", "corpo-a-corpo") else "disparo"))
        x["empunhadura"] = "leve" if natural else (lib.get("empunhadura") or "uma")
        x["criticoM"], x["criticoX"] = at["criticoM"], at["criticoX"]
        x["ataques"] = 1
        per = "luta" if at["categoria"] == "cac" else "pont"
        dano = [[at["dano"], tipo, ""]] + [[fm, tp, ""] for fm, tp in at["dano_extra"]]
        x["rolls"] = [rolagem("Ataque", "ataque", [["1d20", "", ""], [per, "", ""], [str(at["bonus"]), "", ""]], 0),
                      rolagem("Dano", "dano", dano, 1)]
        desc = [p(at["texto"])]
        extras = [e for e in at["extras"]]
        if extras:
            x["chatFlavor"] = "mais " + ", ".join(extras)
            for e in extras:
                hab = next((h for h in f["habilidades"] if norm(h["nome"]) == norm(e)), None)
                if hab:
                    desc.append(f"<p><strong>{html.escape(hab['nome'])}.</strong> {html.escape(hab['texto'])}</p>")
        x["description"]["value"] = "".join(desc)
        return it

    def poder(self, h: dict, f: dict, rel: dict) -> dict:
        auto = automatizar_habilidade(h)
        tem_regra = bool(auto["rolls"] or auto["effects"])
        reuso = None if (tem_regra or auto["decidido"]) else self.bib.poder_identico(h["nome"], h["texto"], f["nome"])
        if reuso:
            it = reuso["item"]
            it["system"]["description"]["value"] = p(h["texto"])
            rel["itens"].append(f"[biblioteca] {h['nome']} (reaproveitado de {reuso['ator']})")
            return it
        it = self._item("poder", h["nome"])
        it["img"] = self.bib.img_poder(h["nome"]) or "icons/svg/item-bag.svg"
        x = it["system"]
        x["tipo"] = "ability"
        x["description"]["value"] = p(h["texto"])
        x["ativacao"].update(execucao=h["execucao"], custo=h["custo"],
                             special=", ".join(h.get("especial") or []))
        if h.get("sustentada"):
            x["duracao"]["units"] = "sust"
        x["rolls"] = auto["rolls"]
        x["resistencia"]["txt"] = auto["resistencia"]
        if auto["alcance"]:
            x["alcance"] = auto["alcance"]
        it["effects"] = auto["effects"]
        rotulo = "[auto]" if tem_regra else "[texto]"
        info = "; ".join(auto["notas"])
        if not tem_regra:
            outros = self.bib.poder_parecido(h["nome"])
            if outros:
                info += f" | há versão configurada à mão (texto diferente) em: {', '.join(outros)}"
        rel["itens"].append(f"{rotulo} {h['nome']}" + (f" — {info}" if info else "")
                            + "".join(f"\n      · {e['name'][:90]}  {[(c['key'], c['value']) for c in e['changes']]}"
                                      for e in auto["effects"])
                            + "".join(f"\n      · rolagem {r['name']}: {r['parts']}" for r in auto["rolls"]))
        return it

    def magia(self, m: dict, f: dict, rel: dict) -> list[dict]:
        auto = automatizar_magia(m)
        base = self.bib.magia(m["nome"])
        if base:
            it = base
            it["_id"] = novo_id()
            for c in ("folder", "ownership", "_stats", "sort"):
                it.pop(c, None)
            it["effects"] = []          # aprimoramentos descartados: a ficha já traz os valores finais
            desc_base = it["system"]["description"]["value"]
            desc_base = re.sub(r"<section[^>]*class=\"secret\"[^>]*>.*?</section>", "", desc_base, flags=re.S)
        else:
            it = self._item("magia", m["nome"])
            desc_base = ""
            rel["avisos"].append(f"magia '{m['nome']}' fora da biblioteca: escola/círculo em branco")
        x = it["system"]
        classe = (f.get("magias_info") or {}).get("classe", "")
        if CLASSE_TIPO.get(classe):
            x["tipo"] = CLASSE_TIPO[classe]
        cab = "%s (%s)" % (m["nome"], m.get("paren", ""))
        x["description"]["value"] = (f"<section class=\"secret\"><p><strong>{html.escape(cab)}</strong> "
                                     f"{html.escape(m['texto'])}</p></section>{desc_base}")
        x["ativacao"].update(execucao=m["execucao"], custo=m["custo"])
        if m["sustentada"]:
            x["duracao"]["units"] = "sust"
        x["rolls"] = auto["rolls"]
        if auto["resistencia"]:
            cd = (f.get("magias_info") or {}).get("cd")
            x["resistencia"]["txt"] = auto["resistencia"] + (f" (CD {cd})" if cd else "")
        it["effects"] = auto["effects"]
        rel["itens"].append(f"[magia] {m['nome']}" + ("" if base else " (sem base na biblioteca)")
                            + "".join(f"\n      · rolagem {r['name']}: {r['parts']}" for r in auto["rolls"])
                            + "".join(f"\n      · buff {[(c['key'], c['value']) for c in e['changes']]}" for e in auto["effects"])
                            + ("".join(f"\n      · obs: {n}" for n in auto["notas"])))
        itens = [it]
        for a in auto["ataques_extras"]:
            cm = re.match(r"(\d+)?/?x?(\d+)?", a["crit"].replace(" ", ""))
            at = {"nome": f"{a['nome'].capitalize()} ({m['nome']})", "qtd": 1, "bonus": a["bonus"],
                  "categoria": "cac", "dano": a["dano"], "tipo": DANO_CANONICO.get(norm(a["nome"])),
                  "criticoM": int(cm.group(1)) if cm and cm.group(1) else 20,
                  "criticoX": int(re.search(r"x(\d+)", a["crit"]).group(1)) if "x" in a["crit"] else 2,
                  "dano_extra": [], "extras": [], "texto": f"Concedido por {m['nome']}."}
            itens.append(self.arma(at, f, rel))
            rel["itens"].append(f"[arma] {at['nome']} (criada a partir do texto da magia)")
        return itens

    # ------------------------------------------------------------ ator
    def ator(self, f: dict) -> tuple[dict, dict]:
        rel = {"nome": f["nome"], "itens": [], "avisos": list(f["avisos"])}
        a = copy.deepcopy(TEMPLATE)
        s = a["system"]
        a["name"] = f["nome"]
        a["img"] = self.img_padrao
        for k, v in f["atributos"].items():
            s["atributos"][k]["base"] = v
        at = s["attributes"]
        at["pv"].update(value=f["pv"], max=f["pv"])
        at["pm"].update(value=f["pm"], max=f["pm"])
        for k, v in f["deslocamento"].items():
            at["movement"]["burrow" if k == "burrow" else k] = v
        at["defesa"]["base"] = f["defesa"]
        at["sentidos"] = {"value": f["sentidos"], "custom": ", ".join(f["sentidos_custom"])}
        at["nd"] = f["nd"]

        d = s["detalhes"]
        d.update(tipo=f["tipo"], raca=f["raca"], role=f["papel"], resistencias=f["resist_texto"],
                 ataquescac=f["ataques_texto"]["cac"], ataquesad=f["ataques_texto"]["ad"],
                 equipamento=f["equipamento"], tesouro=f["tesouro"])

        t = s["tracos"]
        t["tamanho"] = f["tamanho"]
        R = f["resist"]
        for tp in R["imunidades"]:
            t["resistencias"][tp]["imunidade"] = True
        for tp, v in R["reducoes"].items():
            t["resistencias"][tp]["base"] = v
        for tp in R["vulnerab"]:
            t["resistencias"][tp]["vulnerabilidade"] = True
        t["ic"] = {"value": sorted(set(R["ic"])), "custom": "; ".join(R["ic_custom"])}

        P = s["pericias"]
        P["inic"].update(value=f["iniciativa"], treinado=True)
        P["perc"].update(value=f["percepcao"], treinado=True)
        P["fort"]["outros"], P["refl"]["outros"], P["vont"]["outros"] = f["fort"], f["ref"], f["von"]
        for k, v in f["pericias"].items():
            if k in ("fort", "refl", "vont"):
                P[k]["outros"] = v
            else:
                P[k].update(value=v, treinado=True)

        tam = TOKEN.get(f["tamanho"], 1)
        tok = a["prototypeToken"]
        tok.update(name=f["nome"], width=tam, height=tam, disposition=-1)
        tok["texture"]["src"] = self.img_padrao

        itens = []
        for ataque in f["ataques"]:
            itens.append(self.arma(ataque, f, rel))
            rel["itens"].append(f"[arma] {itens[-1]['name']}: +{ataque['bonus']} "
                                f"{[r['parts'] for r in itens[-1]['system']['rolls'] if r['type'] == 'dano'][0]} "
                                f"crít {ataque['criticoM']}/x{ataque['criticoX']}")
        # resistência a magia (linha de Defesa) vira poder com efeito de teste
        for o in R["outros"]:
            if re.search(r"resist[eê]ncia a magia \+\d+", o):
                it = self._item("poder", o[0].upper() + o[1:])
                it["system"]["tipo"] = "ability"
                it["system"]["description"]["value"] = p(o)
                it["effects"] = bonus_testes(it["name"], o)
                itens.append(it)
                rel["itens"].append(f"[auto] {it['name']} — efeito de teste (marcar ao resistir a magia)")
        for h in f["habilidades"]:
            itens.append(self.poder(h, f, rel))
        if f["magias_info"]:
            it = self._item("poder", "Magias")
            it["system"]["tipo"] = "ability"
            it["system"]["description"]["value"] = p(f["magias_info"]["texto"])
            itens.append(it)
            for m in f["magias"]:
                itens += self.magia(m, f, rel)
        a["items"] = itens
        a["flags"] = {"t20conv": {"versao": 1}}
        return a, rel

##### ARQUIVO: t20conv/biblioteca.py #####
"""Biblioteca de referência construída a partir de compêndios já configurados à mão
(ex.: o módulo ameacas-de-arton-cdm e o compêndio de magias do sistema).

Uso: python -m t20conv.biblioteca <fonte> [<fonte> ...] -o biblioteca.json
  <fonte> = pasta com JSONs (um por documento, como o foundryvtt-cli gera)
            ou arquivo .json com uma lista de documentos (como a macro exportar_compendio gera).
Aceita atores (os itens deles entram no índice) e itens soltos.
"""
from __future__ import annotations

import argparse
import collections
import copy
import html
import json
import random
import re
import string
from pathlib import Path

from .parser import norm


def novo_id() -> str:
    return "".join(random.choices(string.ascii_letters + string.digits, k=16))


def texto_puro(h: str) -> str:
    h = re.sub(r"@UUID\[[^\]]*\]\{([^}]*)\}", r"\1", h or "")
    h = re.sub(r"<section[^>]*class=\"secret\"[^>]*>.*?</section>", " ", h, flags=re.S)
    h = re.sub(r"<[^>]+>", " ", h)
    return re.sub(r"\s+", " ", html.unescape(h)).strip()


def chave_texto(txt: str, nome_criatura: str = "") -> str:
    n = norm(txt)
    if nome_criatura:
        n = n.replace(norm(nome_criatura), "<c>")
    return re.sub(r"[^\w<>+\-/ ]", "", n).strip()


def _docs(fonte: Path):
    if fonte.is_dir():
        for fp in sorted(fonte.glob("*.json")):
            yield json.loads(fp.read_text(encoding="utf-8"))
    else:
        dados = json.loads(fonte.read_text(encoding="utf-8"))
        yield from (dados if isinstance(dados, list) else [dados])


def construir(fontes: list[Path]) -> dict:
    poderes: dict[str, list] = collections.defaultdict(list)
    magias: dict[str, dict] = {}
    armas: dict[str, dict] = {}
    tipos_arma = collections.defaultdict(collections.Counter)

    def add_item(it, ator=""):
        nome = norm(it.get("name", ""))
        if not nome:
            return
        x = it.get("system", {})
        if it["type"] == "poder":
            txt = texto_puro(x.get("description", {}).get("value", ""))
            poderes[nome].append({"ator": ator, "chave": chave_texto(txt, ator),
                                  "tem_automacao": bool(it.get("effects") or x.get("rolls")),
                                  "item": it})
        elif it["type"] == "magia":
            atual = magias.get(nome)
            # prefere a versão "de livro" (sem ator) ou a primeira vista
            if atual is None or (atual["ator"] and not ator):
                magias[nome] = {"ator": ator, "item": it}
        elif it["type"] == "arma":
            for r in x.get("rolls", []):
                if r.get("type") == "dano" and r.get("parts") and r["parts"][0][1]:
                    tipos_arma[nome][r["parts"][0][1]] += 1
            a = armas.setdefault(nome, {"img": it.get("img"), "proficiencia": x.get("proficiencia"),
                                        "proposito": x.get("proposito"),
                                        "empunhadura": x.get("empunhadura"),
                                        "criticoM": x.get("criticoM"), "criticoX": x.get("criticoX")})
            if a["img"] in (None, "icons/svg/item-bag.svg"):
                a["img"] = it.get("img")

    for f in fontes:
        for d in _docs(Path(f)):
            if d.get("type") in ("npc", "character"):
                for it in d.get("items", []):
                    add_item(it, d.get("name", ""))
            elif d.get("type") in ("poder", "magia", "arma"):
                add_item(d)
    for n, c in tipos_arma.items():
        armas[n]["tipos"] = dict(c)
    return {"poderes": poderes, "magias": magias, "armas": armas}


class Biblioteca:
    def __init__(self, dados: dict | None = None):
        d = dados or {"poderes": {}, "magias": {}, "armas": {}}
        self.poderes, self.magias, self.armas = d["poderes"], d["magias"], d["armas"]

    @classmethod
    def carregar(cls, caminho: str | Path | None) -> "Biblioteca":
        if not caminho or not Path(caminho).exists():
            return cls()
        return cls(json.loads(Path(caminho).read_text(encoding="utf-8")))

    def poder_identico(self, nome: str, texto: str, criatura: str) -> dict | None:
        """Poder já configurado com o MESMO texto (descontando o nome da criatura)."""
        alvo = chave_texto(texto, criatura)
        cands = [c for c in self.poderes.get(norm(nome), []) if c["chave"] == alvo and c["tem_automacao"]]
        if not cands:
            return None
        it = copy.deepcopy(cands[0]["item"])
        it["_id"] = novo_id()
        for campo in ("folder", "ownership", "_stats", "sort"):
            it.pop(campo, None)
        for e in it.get("effects", []):
            e["_id"] = novo_id()
            e.pop("origin", None)
            e.pop("_stats", None)
        return {"item": it, "ator": cands[0]["ator"]}

    def poder_parecido(self, nome: str) -> list[str]:
        return sorted({c["ator"] for c in self.poderes.get(norm(nome), []) if c["tem_automacao"]})[:5]

    def img_poder(self, nome: str) -> str | None:
        for c in self.poderes.get(norm(nome), []):
            img = c["item"].get("img")
            if img and not img.startswith("icons/svg/"):
                return img
        return None

    def magia(self, nome: str) -> dict | None:
        m = self.magias.get(norm(nome))
        return copy.deepcopy(m["item"]) if m else None

    def arma(self, nome: str) -> dict | None:
        return self.armas.get(norm(nome))


def main():
    ap = argparse.ArgumentParser(description=__doc__, formatter_class=argparse.RawDescriptionHelpFormatter)
    ap.add_argument("fontes", nargs="+", type=Path)
    ap.add_argument("-o", "--saida", default="biblioteca.json")
    a = ap.parse_args()
    dados = construir(a.fontes)
    Path(a.saida).write_text(json.dumps(dados, ensure_ascii=False), encoding="utf-8")
    print(f"biblioteca: {sum(len(v) for v in dados['poderes'].values())} poderes "
          f"({len(dados['poderes'])} nomes), {len(dados['magias'])} magias, "
          f"{len(dados['armas'])} armas -> {a.saida}")


if __name__ == "__main__":
    main()

##### ARQUIVO: tools/extrair_pdf.py #####
"""Extrai fichas de ameaças de um PDF de Tormenta20 para o formato de texto do conversor.

  python tools/extrair_pdf.py livro.pdf --paginas 140-145 -o fichas/livro.txt
  python tools/extrair_pdf.py livro.pdf --paginas 142 --diagnostico      # fontes de cada trecho

Como funciona: lê cada trecho de texto com a fonte (PyMuPDF). Trechos em negrito viram
**rótulos**, itálico vira *itálico*. Uma ficha começa no título acima de "Iniciativa"
e termina no "Tesouro". Fichas são separadas por "===".

ATENÇÃO: ainda não calibrado com o PDF real (fontes de versalete, ícones, duas colunas).
Rode com --diagnostico numa página com ficha e mande a saída para ajustar.
"""
from __future__ import annotations

import argparse
import re
import sys

try:
    import pymupdf as fitz
except ImportError:  # versões antigas
    import fitz

NEGRITO = re.compile(r"bold|black|heavy|semibold|demi|hebo|-b\b", re.I)
ITALICO = re.compile(r"italic|oblique|heit", re.I)


def paginas(spec: str, total: int):
    out = []
    for parte in spec.split(","):
        a, _, b = parte.partition("-")
        out += range(int(a), int(b or a) + 1)
    return [p for p in out if 1 <= p <= total]


def linhas_da_pagina(pg) -> list[dict]:
    """Linhas com spans, ordenadas por coluna e depois por altura."""
    meio = pg.rect.width / 2
    linhas = []
    for b in pg.get_text("dict")["blocks"]:
        for l in b.get("lines", []):
            spans = [s for s in l["spans"] if s["text"].strip()]
            if not spans:
                continue
            x0, y0 = l["bbox"][0], l["bbox"][1]
            largura = l["bbox"][2] - x0
            col = 0 if (x0 < meio and largura < meio * 1.2) or largura >= meio * 1.2 and x0 < meio else 1
            linhas.append({"col": col, "y": round(y0, 1), "x": x0, "spans": spans,
                           "tam": max(s["size"] for s in spans)})
    linhas.sort(key=lambda l: (l["col"], l["y"], l["x"]))
    return linhas


def marca(spans) -> str:
    out = ""
    for s in spans:
        t = s["text"]
        neg = bool(s["flags"] & 16) or bool(NEGRITO.search(s["font"]))
        ita = bool(s["flags"] & 2) or bool(ITALICO.search(s["font"]))
        if neg and t.strip():
            t = f"**{t.strip()}** " if not t.startswith(" ") else f" **{t.strip()}** "
        elif ita and t.strip():
            t = f"*{t.strip()}* " if not t.startswith(" ") else f" *{t.strip()}* "
        out += t
    out = re.sub(r"\*\*\s*\*\*", " ", out)          # funde negritos vizinhos
    return re.sub(r"\s+", " ", out).replace(" ,", ",").replace(" .", ".").strip()


def extrair(doc, pags) -> list[str]:
    todas = []
    for n in pags:
        todas += linhas_da_pagina(doc[n - 1])
    txt = [marca(l["spans"]) for l in todas]
    fichas, i = [], 0
    while i < len(txt):
        if re.match(r"^\*\*\s*iniciativa", txt[i], re.I):
            ini = i
            # sobe até 4 linhas atrás para pegar nome / ND / tipo
            while ini > 0 and i - ini < 4 and not re.search(r"tesouro", txt[ini - 1], re.I):
                ini -= 1
            fim = i
            while fim < len(txt) and not re.match(r"^\*\*\s*tesouro|.*\*\*\s*tesouro\s*\*\*", txt[fim], re.I):
                fim += 1
            # o "Tesouro" pode quebrar linha: pega a continuação se não for rótulo
            fim2 = fim + 1
            while fim2 < len(txt) and not txt[fim2].startswith("**") and fim2 - fim < 2 \
                    and not re.search(r"\bND\b", txt[fim2]):
                fim2 += 1
            bloco = txt[ini:fim2]
            nd = next((b for b in bloco[:5] if re.fullmatch(r"\**\s*ND\s*[\d/]+\s*\**", b)), None)
            cab = [re.sub(r"\*", "", b) for b in bloco[:i - ini]]
            corpo = bloco[i - ini:]
            fichas.append("\n".join(cab + ([] if nd else []) + corpo))
            i = fim2
        else:
            i += 1
    return fichas


def main():
    ap = argparse.ArgumentParser(description=__doc__, formatter_class=argparse.RawDescriptionHelpFormatter)
    ap.add_argument("pdf")
    ap.add_argument("--paginas", required=True, help="ex.: 140-145 ou 12,15,20-22 (numeração do PDF)")
    ap.add_argument("-o", "--saida")
    ap.add_argument("--diagnostico", action="store_true")
    a = ap.parse_args()
    doc = fitz.open(a.pdf)
    pags = paginas(a.paginas, len(doc))
    if a.diagnostico:
        for n in pags:
            print(f"===== página {n}")
            for l in linhas_da_pagina(doc[n - 1]):
                print(f"[c{l['col']} y{l['y']:.0f}] " + " | ".join(
                    f"{s['text']!r}<{s['font']},{s['size']:.1f},f{s['flags']}>" for s in l["spans"]))
        return
    fichas = extrair(doc, pags)
    saida = "\n===\n".join(fichas) + "\n"
    if a.saida:
        open(a.saida, "w", encoding="utf-8").write(saida)
        print(f"{len(fichas)} ficha(s) -> {a.saida}", file=sys.stderr)
    else:
        print(saida)


if __name__ == "__main__":
    main()

        if (x.get("duracao") or {}).get("units"): cnt["duration_units"][x["duracao"]["units"]] += 1
        for rl in x.get("rolls", []):
            cnt["roll_tipos"][(it["type"], rl.get("type"), rl.get("name"))] += 1
            for p in rl.get("parts", []):
                if len(p) > 2: cnt["roll_part_tags"][(rl.get("type"), p[2])] += 1
                if rl.get("type") == "dano" and len(p) > 1: cnt["dano_tipos"][p[1]] += 1
            if rl.get("type") == "ataque": cnt["atk_parts"][tuple(("N" if str(p[0]).lstrip("+").isdigit() else p[0]) for p in rl["parts"])] += 1
        for e in it.get("effects", []):
            fl = (e.get("flags") or {}).get("tormenta20", {})
            sig = tuple(k for k in ("onuse","self","attack","skill","spell","power","ability","equipment","consumable","aumenta","durationScene") if fl.get(k)) + (("items="+fl["items"],) if fl.get("items") else ())
            cnt["eff_flags"][(it["type"], sig, e.get("transfer"), e.get("disabled"))] += 1
            for ch in e["changes"]:
                cnt["eff_key"][ch["key"]] += 1
                cnt["eff_mode"][(ch["key"], ch["mode"])] += 1
                if len(ex[ch["key"]]) < 4: ex[ch["key"]].append(f'{d["name"]}/{it["name"]}: {ch["value"]!r} m{ch["mode"]} | {e["name"][:70]}')
print("atores npc:", atores)
for k, c in cnt.items():
    print(f"\n== {k} ({sum(c.values())})")
    for v, n in c.most_common(45): print(f"  {n:5} {v}")
print("\n== exemplos por chave de efeito")
for k, l in sorted(ex.items()):
    print(" ", k); [print("     ", y) for y in l]

"""Roda o motor de regras sobre todos os poderes de uma biblioteca e compara com a
configuração feita à mão. Uso: python tools/avaliar_regras.py biblioteca.json [n_exemplos]"""
import collections
import json
import random
import sys
from pathlib import Path

sys.path.insert(0, str(Path(__file__).resolve().parent.parent))
from t20conv.biblioteca import texto_puro  # noqa: E402
from t20conv.regras import automatizar_habilidade  # noqa: E402

bib = json.load(open(sys.argv[1], encoding="utf-8"))
n_ex = int(sys.argv[2]) if len(sys.argv) > 2 else 6
cat = collections.Counter()
ex = collections.defaultdict(list)
for nome, lst in bib["poderes"].items():
    for c in lst:
        it = c["item"]
        x = it["system"]
        txt = texto_puro(x.get("description", {}).get("value", ""))
        if not txt or len(txt) < 15:
            continue
        h = {"nome": it["name"], "execucao": (x.get("ativacao") or {}).get("execucao", ""),
             "custo": (x.get("ativacao") or {}).get("custo", 0), "sustentada": False, "texto": txt}
        a = automatizar_habilidade(h)
        mao = bool(it.get("effects") or x.get("rolls"))
        regra = bool(a["effects"] or a["rolls"])
        k = {(True, True): "ambos", (True, False): "só à mão", (False, True): "só regras",
             (False, False): "nenhum"}[(mao, regra)]
        cat[k] += 1
        ex[k].append((c["ator"], it["name"], txt[:170],
                      [(r["name"], r["parts"]) for r in x.get("rolls", [])][:2],
                      [[(ch["key"], ch["value"]) for ch in e["changes"]] for e in it.get("effects", [])][:2],
                      [(r["name"], r["parts"]) for r in a["rolls"]][:2],
                      [[(ch["key"], ch["value"]) for ch in e["changes"]] for e in a["effects"]][:2]))
print(cat)
random.seed(1)
for k in ("ambos", "só à mão", "só regras"):

# t20conv — fichas de ameaças de Tormenta20 → atores do Foundry VTT

Converte o bloco de estatísticas de uma ameaça (texto ou PDF) em um ator NPC do sistema
**tormenta20** (testado com o formato da v1.4.213 / Foundry v12), com ataques, rolagens,
magias e efeitos ativos já configurados. Sem custo de tokens: tudo roda local, em Python.

## Instalação

Python 3.10+ e, para ler PDF, `pip install pymupdf`.

## Fluxo

```
PDF ──tools/extrair_pdf.py──▶ fichas/*.txt ──converter.py──▶ saida/*.json ──macro──▶ Foundry
                                                  ▲
                         biblioteca.json (seu compêndio configurado à mão)
```

1. **Biblioteca (uma vez):** no Foundry, rode a macro `macros/exportar_compendio.js` e exporte
   `ameacas-de-arton-cdm.ameacas` e `tormenta20.magias`. Depois:
   `python -m t20conv.biblioteca ameacas-de-arton-cdm.ameacas.json tormenta20.magias.json -o biblioteca.json`
   (também aceita as pastas que o `foundryvtt-cli unpack` gera).
2. **Extrair do PDF:** `python tools/extrair_pdf.py livro.pdf --paginas 140-150 -o fichas/cap5.txt`
   e revise o .txt rapidamente (é texto simples).
3. **Converter:** `python converter.py fichas/ -o saida/ --biblioteca biblioteca.json`
4. **Importar:** macro `macros/importar_atores.js` → escolha `saida/_todos.json`.
   (Ou um ator só: botão direito num ator → *Import Data* → `saida/<nome>.json`.)
5. Leia `saida/_relatorio.txt`: diz o que foi automatizado e o que ficou só em texto.

## Formato do texto da ficha

```
ONI
ND 5
Espírito Médio [solo]                 ← [solo] / [especial] / [lacaio] (padrão: solo)
**Iniciativa** +5, **Percepção** +3, faro, visão na penumbra
**Defesa** 24, **Fort** +17, **Ref** +11, **Von** +5, imunidade a doenças, fogo e veneno, redução de dano 5
**Pontos de Vida** 200
**Deslocamento** 9m (6q)
**Corpo a Corpo** Machado de guerra +17 (1d12+16, x3) e chifres +17 (1d6+10 mais doença).
**Avesso à Honra** Os ataques do oni causam +1d10 pontos de dano de trevas contra ...
**Magias** Como um mago de 14º nível (CD 38, limite de PM 23).
• *Bola de Fogo (Padrão, 11 PM)* O dracomante causa 15d6+23 pontos de dano de fogo ...
**For** 5, **Des** 1, **Con** 3, **Int** 0, **Sab** –1, **Car** –2
**Perícias** Atletismo +9, Intimidação +7.
**Equipamento** Machado de guerra. **Tesouro** Padrão.
```
Rótulos em `**negrito**`; linhas quebradas e hifenização são juntadas sozinhas; várias fichas
num arquivo são separadas por uma linha `===`. Exemplos em `exemplos/fichas/`.

## O que é automatizado

| Na ficha | No Foundry |
|---|---|
| Atributos, PV, PM, Defesa, deslocamentos, sentidos, ND, tipo, tamanho, papel | campos do ator; tamanho do token |
| Fort/Ref/Von, Iniciativa, Percepção, perícias | perícias (mesma convenção do compêndio) |
| imunidades, redução de dano/energia, vulnerabilidades | resistências; imunidade a condições (`ic`) |
| resistência a magia +N | poder com efeito de teste (Vontade/Reflexos/Fortitude) |
| ataques `nome +N (dano, crítico mais X)` | arma com ataque, dano **tipado**, margem/multiplicador; "duas garras" etc. |
| "mais doença/veneno" num ataque | texto da habilidade copiado na descrição da arma |
| `(Execução, N PM)` | execução e custo da habilidade/magia |
| "sofre/causa XdY pontos de dano de T [mais ...]" | rolagem de dano (com tipos) |
| "cura XdY", "PV temporários", "perde XdY PV" | rolagem de cura / PV temp. / perda |
| "manobra derrubar … (teste +19)" | rolagem `d20+19` chamada "Derrubar" |
| "(Ref CD 38 reduz à metade)" | resistência da habilidade |
| **bônus condicional em ataques** (Avesso à Honra etc.) | efeito *ao usar* marcável no diálogo de ataque, com tipo: `1d10[trevas]` |
| bônus condicional em testes ("+5 em Vontade se…") | efeito *ao usar* de teste |
| buffs com duração ("recebe +5 na Defesa por 1 turno", RD, voo, atributos) | efeito: aplicado ao usar (ativas) ou alternável (gatilhos) |
| "muda a execução para livre" (Magia Acelerada) | efeito *ao usar* em magias, com custo em PM |
| magias da ficha | item de magia com escola/círculo/ícone da biblioteca + dano/cura/CD **finais** da ficha |
| ataque concedido por magia (mordida da Transformação em Dragão) | arma extra |
| "(já contabilizado)" | ignorado de propósito, para não somar duas vezes |
| poder com texto idêntico a um já configurado no compêndio | reaproveita o item feito à mão |

Bônus permanentes ("recebe +2 em Furtividade") **não** viram efeito, porque os números do
livro já os incluem.

## Ferramentas de apoio

- `tools/avaliar_regras.py biblioteca.json` — roda as regras em todos os poderes do compêndio e
  compara com o que foi feito à mão (hoje: 478 iguais/compatíveis, 162 só pelas regras).
- `tools/extrair_pdf.py --diagnostico` — mostra fontes/negrito de cada trecho, para calibrar.
- `tools/gerar_template.py` — regenera o esqueleto de ator/itens a partir de um ator exportado.
